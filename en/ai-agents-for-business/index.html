Direct answer

Answering is one capability. Acting is another responsibility.

A chatbot generates responses within a conversation. An AI agent may also retrieve information, use tools and prepare or execute actions to complete a defined task. Doing so responsibly requires trusted context, least-privilege access, clear limits, activity records, evaluation and an accountable human. TRICOT designs that layer and defines where human approval must remain.

Operational risk

The problem is not only a wrong answer. It is a correct action based on the wrong data.

When AI uses business sources or tools, each ambiguity can become an incorrect action, permission or operational record.

The task must be scoped before autonomy expands.

01Two sources provide different states.

02The agent accesses information the user should not see.

03A correct action runs against the wrong entity.

04Nobody can reconstruct which source it used.

05An exception is treated as a rule.

The fact that AI can do it does not mean it should do it alone.

FAQ

Questions about AI agents.

The page avoids general autonomy, accuracy guarantees and unverified compatibility claims.

What is the difference between a chatbot and an agent?

An agent may use sources and tools to complete a task; the exact boundary depends on architecture rather than a marketing label.

Can it use company tools?

Yes, when the integration, permissions, parameters and fallback have been verified.

Which actions need approval?

Sensitive, irreversible or consequential actions according to the agreed use case and risk.

How do you verify it works?

With samples, expected answers, tolerated errors, records, costs and human review.

What happens when a source or API fails?

The system should stop, reduce capability or use fallback without hiding the failure.

When is an agent inappropriate?

When a stable task, trusted sources, permissions, ownership, evaluation or safe intervention are missing.
